# Shop 🛒

Simple online shop demo built with **React** + **TypeScript** and bundled with **Webpack**.

[Live Demo](https://dedkik.github.io/shop/) • [Report Issues](https://github.com/DeDKiK/shop/issues)

## About the Project

A minimalistic e-commerce frontend demonstration featuring:  
- Product listing  
- Shopping cart functionality  
- Cart context & custom hooks  
- Responsive layout basics  

Built as a learning / portfolio project.

## Technologies

- React 18  
- TypeScript  
- Webpack + Babel  
- CSS (vanilla / modules)

## How to run locally

```bash
# 1. Clone the repository
git clone https://github.com/DeDKiK/shop.git
cd shop

# 2. Install dependencies
npm install

# 3. Start development server
npm start
